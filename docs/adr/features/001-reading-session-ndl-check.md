## 7-2 での問い合わせの形
- 1件ずつ、次の形で問い合わせる。dpid に iss-ndl-opac と iss-ndl-opac-inprocess の2つを空白区切りで入れる（URL の中では空白を %20 にする）。
  - `https://ndlsearch.ndl.go.jp/api/opensearch?dpid=iss-ndl-opac%20iss-ndl-opac-inprocess&isbn=<ISBN13>`
- 「そろう」の数え方（ここで先に決める）
  - 書名：dc:title が空でない。
  - 著者：PRD の 11 の冒頭の決まりで、空でない著者が取れる（dc:creator の1つ目、なければ author の要素の最後の「,」の後ろ。区切り、生没年と役割の語の除き方も同じ決まり）。
  - 出版社：dc:publisher が空でない。
  - 1つの ISBN に item が2件以上返ったら、最初の item で数える（アプリが使う形に合わせる）。7-2 の ADR 0004 で別の選び方にするなら、その選び方でも別に数えて両方を記録する。合否は最初の item で決める。
  - 0件なら「そろわない」。
- 記録する列（7-2）：返った件数、最初の item の書名、取り出した著者、出版社、どちらの書誌から返ったか（分かれば）、応答の時刻。
- openBD の結果は合否に入れない。使うかは ADR 0004 で決め、問い合わせるなら別の列に記録する。
- 問い合わせの間は1秒以上空ける［推測。国立国会図書館サーチの利用の決まりは 7-2 で読む］。
- 7-2 の問い合わせが 2026-10-20 にできないときは、問い合わせずに指揮役に返す。新刊の窓（15〜28日前）が動くので、行を選び直すかは指揮役が決める。
