## 書誌の取り方（2026-10-20）
- 前提として伝えたこと：3体の調べもののまとめ（docs/reviews/001-reading-session-biblio-alt-proposal.md）。3体とも外部 API を使わない形（F：バーコードの ISBN、奥付か表紙を写して行を押す、手で入れる）を推した。いちばん強い反論は、登録が1冊10〜20秒に重くなり、ほかのアプリのように自動では埋まらないこと。
