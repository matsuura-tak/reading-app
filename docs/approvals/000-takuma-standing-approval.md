## 指揮役の読み方
- 「確認する部分は全て承認、推奨で進めて」：各関門で Takuma に決めてほしいことは、役が付けた推奨どおりに指揮役が決め、docs/approvals/<機能名>-G0.md にこの文書を根拠として引用する。条件は付いていないので承認として扱う。
- 「稼ぐこと」と「レッドドット賞」が指標：PRD の North Star、収益化、Red Dot の応募条件を pdm と designer の調査に含める。
- 「今の API の案に縛られず」：app.json の idea と、いままでの案は出発点であって制約ではない。読書アプリの土俵の中で、2つの指標に最も効く形を推奨してよい。
- 「権限周りで引っかかったらすぐに伝えて」：.claude/、.github/ の変更（app.json の commands など）、main へのマージ、ストア提出が必要になった時点で、まとめて具体的に知らせる。
- この承認で Takuma の代わりにできないこと（docs/org/gates.md）：main へのマージ、実機での確認、App Store への提出、課金の操作、.claude/ と .github/ の変更。
