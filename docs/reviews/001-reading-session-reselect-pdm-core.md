## 0. 結論
- **共通の芯は確かです。**
  - 25〜59歳でオーディオブックを使わない人の41.9%が「読みたいのに読めていない」と答えました。
  - 16歳以上の69.1%が「読書量が減った」と答えています。
- **つまずく場所は「スマホ」と「疲れ」がほぼ同じ大きさで、「迷う」はずっと小さいです。**
  - 読書量が減った理由は、スマホが43.6%、仕事や勉強が38.9%でした（令和5年度）。
  - 平成25年度の「良い本の選び方が分からない」は3.6%でした。
- **3つは別々の悩みではなく、同じ夜に続けて起きる場面です。** 三宅香帆の本の帯は「疲れてスマホばかり見てしまうあなたへ」です。
- **指揮役の仮説（本棚にカメラを向けると光る）は、映えはいちばん強いです。**
  - ただし、いちばん小さな悩み（迷う）に、いちばん難しい技術（日本語の縦書きの背表紙を見分ける）を当てる形です。
  - 同じ瞬間を持つアプリが、日本の Bookpather（2026-07）と米国の Shelf Scan（2025-11）にすでにあります。どちらも評価は0〜2件で、人を集めていません。
- **pdm の推し：「疲れた夜にスマホを手に取った瞬間」の1つに絞ります。**
  - 入口は案 A「続きの一行」にします。ロック画面に昨夜読み終えた一行が縦書きで出て、伏せると続きが始まる形です。
  - 本棚が光る場面は、あとから週末の取り込みとして足せる形にとどめます。最初の2週間には入れません。
  - 条件は、6 の安い確かめを先に通すことです。
- **いちばん強い反論：「わかる」と「使い続ける」は別です。**
  - 読書に絞った習慣や集中のアプリは、日本でも海外でも、出ても伸びていません。いちばん多い mekuru でも362件です。
  - この悩みにお金が払われているのは、別の2つです。1つは、読むのをやめて要約や耳に置き換える側です（Audible 156,681件）。もう1つは、スマホを止める側です（Blockin 19,525件）。

## 2. 「スマホで長い文章が読めなくなった」の需要

### 2-1 日本
- 文化庁の令和5年度の調査では、スマホが読書が減った理由の1位（43.6%）で、若いほど高くなっています（1-2）。

## 4. 共通の芯「読みたいのに、読むところまでたどり着けない」

### 4-1 つまずく場所の大きさ
| つまずく場所 | いちばん近い数字 | 出典 |
|---|---|---|
| スマホに引っ張られる（集中） | 減った理由の1位で43.6%（16〜19歳は70.9%、20〜30代は6割台）。諦める理由の2位「気力・集中力が続かない」25.9% | 文化庁 R5、オトバンク |
| 疲れ、時間（仕事） | 減った理由の2位で38.9%（20〜40代は6割台）。諦める理由の1位「時間がない」34.5%、3位「目や身体の疲れ」21.6%。働く人の読書の課題の1位「時間の確保」39.5% | 文化庁 R5、オトバンク、壺中天 |
| 迷う（選べない、積読） | 平成25年度の「良い本の選び方が分からない」3.6%、「魅力的な本が減っている」8.5%。令和5年度の値は概要の文に出てこない（グラフの画像で、読めていない） | 文化庁 H25 |

- **読み方：** スマホと疲れがほぼ同じ大きさで、迷うはその10分の1ほどです。
- **注意1：** 「減った理由」を聞くと、外の理由を選びやすくなります。
- **注意2：** 積読は「本を買う人」の悩みで、この調査の母数（16歳以上の全員）とは違います。別の pdm の積読の結果と並べて見てください。
  - 『私は積読家』（149件）の打ち出しは「積読は、減らさなくていい」です。積読の人にとって、迷うことは痛みではないかもしれません。［推測］
- **注意3：** 「気力・集中力が続かない」は、疲れと集中の両方にまたがっています。
- **3つは同じ夜に続けて起きます。** 疲れて帰り、スマホを手に取り、本を選ぶ気力が出ません。帯の「疲れてスマホばかり見てしまう」が、まさにこの場面です。［公開情報 bunshun］ だから、狙う場面は本棚の前ではなく、「疲れた夜、スマホが手の中にある瞬間」です。［推測］

### 4-2 Job（仮の1文。画面や機能の名前は入れていません）
- 仕事を終えて疲れた夜、手がスマホに伸びそうなとき、考えず、気力も使わずに、本の続きに入りたい。そうすれば、「読みたいのに読めない」日が減り、読んでいる自分に戻れる。［推測。調査からまとめた仮の文］

### 4-3 3つを1つで解く案
どの案にも、指揮役の仮説にある「数ページで終われる」（やめてよいことをはっきり示す）を入れます。疲れには、量の線を下げることが効くはずです（オトバンクの「気力・集中力が続かない」25.9%）。［推測］

**案 A「続きの一行」**
- **流れ**
  1. 読み終えたら、止めたページを1枚撮ります。アプリが最後の数行を切り出し、縦書きで組みます。
  2. 夜、自分で決めた時刻から、ロック画面（ウィジェット）に、その一行とページ番号だけが出ます。
  3. 伏せると読書が始まり、持ち上げると終わります。
- **3つへの効き方**
  - 迷う：選ばなくてよくなります。いつも続きから始まります。
  - 疲れ：前回どこまで読んだかを思い出す手間が要りません。
  - スマホ：スマホを手に取ったとき、最初に見える画面が本の一行になります。
- **象徴の瞬間：** 夜、iPhone を持ち上げると、通知より先に、昨夜読み終えた一行が縦書きの明朝で浮かんでいます。そのまま伏せると画面が消え、続きが始まります。
- **近い先行**
  - ロック画面に「読書中の本」を出すもの：Bookpather Pro、ToRead Plus、Bookmory。
  - ページの文字の読み取り：Bookmory、Readrrr。
  - 最後に読んだ一行を入口にするものは、見た範囲にはありませんでした。［公開情報。上位だけ見た］

**案 B「夜の盾」**
- **流れ：** 夜の決めた時間帯に SNS を開くと、止める画面が文庫の1ページの姿で出ます（本の題、ページ、続きの一行）。伏せて10分読むと、その夜は SNS が開きます。
- **3つへの効き方**
  - スマホ：減った理由の1位に、正面から当たります。
  - 疲れ：10分と短く済みます。
  - 迷う：続きを出すので選ばなくて済みます。
- **象徴の瞬間：** Instagram のアイコンを押すと、画面が文庫の1ページに変わり、「124ページから。伏せて10分」とだけ出ます。
- **近い先行**
  - Pause（JP）の「開く前に、読書という選択肢。」、Opal の盾に出る言葉、Pagelock、ReadUp、Actually Read（designer の報告と pdm-12）。
  - 盾の画面を文庫の姿にできるかは、まだわかりません。designer の報告の ① に「盾の画面の作りの制約」の節があります。

### 4-4 指揮役の仮説（案 X「今夜の一冊」）の評価
- **流れ：** 本棚にカメラを向けると、今夜の1冊が光ります。伏せると読み始め、数ページで終われます。
- **象徴の瞬間：** 本棚にかざした画面の中で、1冊の背表紙だけがふっと光ります。
- **強み**
  - 10秒の映えは、候補の中でいちばん強いです。
  - 3つのつまずきを、起きる順に1本の流れで見せられます。
  - 紙の本と縦書きの背表紙は日本らしく、ADA の「文化の固有性」（designer の T-5）に合います。［推測］
- **弱み1：先行があります。**
  - Bookpather（JP、2026-07）が、「本棚をスキャンして次に読む本を決め、読書時間を計り」をすでに出しています。
  - Shelf Scan（US）は、写真1枚から「次に読む本」を選ぶ、同じ瞬間を持っています。
  - どちらも評価は0〜2件です。［公開情報］
- **弱み2：いちばん小さな悩みに、いちばん難しい技術を当てます。**
  - 迷うことは、減った理由として3.6%と小さいです（H25）。
  - 縦書きの日本語の背表紙を見分けるのは、3案の中でいちばん作るのが難しい部分です（tech-lead に要確認）。
  - 見分けに失敗すると★1が付きます。Readrrr の OCR の不満が、その例です。［公開情報］
- **弱み3：いちばん映える瞬間が、いちばん起きません。**
  - 本を選ぶのは、1冊を読み終えたとき（数週間に1回）だけです。［推測］
  - 毎晩起きるのは「伏せる」で、これは2018年からあります。
- **弱み4：疲れと逆を向きます。**
  - 疲れた夜に、本棚の前でカメラを向ける手順が1つ増えます。
  - Forest への「演出が手順を増やす」という不満と同じ形です（product.md の 4）。［推測］
- **弱み5：電子書籍の人を外します。**
  - 電子書籍を使う人は40.3%です。30代では、使う人の51.3%が「電子の方が多い」と答えています。［公開情報 R5 の概要 p.30〜33］
  - 紙の本棚が前提だと、スマホで読む人、つまり SNS に引っ張られやすい人を外します。［推測］
- **直し方の案：「選ぶのは元気なとき、読むのは疲れたとき」に分けます。**
  - 本棚を撮るのは週末に1回にして、取り込みと「今週の3冊」に使います。
  - 毎晩の入口は、案 A のロック画面にします。
  - 映えるのは週末の場面、価値が出るのは毎晩の場面です。［推測］
  - ただし作る量は増えるので、2週間に入るかは tech-lead の判断です。

## 6. いちばん強い反論と、いちばん安い確かめ方

### 反論
- **「わかる」と「使い続ける」は別です。**
  - 読めない原因は、働き方と疲れという構造です。著者の答えも「全身全霊をやめる」という働き方の話です（要約のみ）。アプリで動かせる部分は小さいです。［推測］
  - 読書に絞った習慣や集中のアプリは、日本でも海外でも伸びていません。
    - Pause 18件、Pagelock 7件、ReadUp 9件、Offshelf 4件、Actually Read 10件、Bookpather は評価なし、Shelf Scan 2件。
    - いちばん多い mekuru でも362件です。［公開情報］
  - この悩みにお金が払われているのは、読むのをやめて要約や耳に置き換える側（Audible 156,681件）と、止める側（Blockin 19,525件）です。
- **悩みが強い人ほど、読書アプリを入れません。**
  - 月0冊の人のうち、「読みたいのに読めていない」と感じているのは24.6%だけです。［公開情報 オトバンク］
  - 読書アプリを入れるのは、すでに読んでいる人です。［推測］
- **作らない場合に起きること：**
  - Takuma のポートフォリオの1本ができません。
  - この悩みは、要約、耳、止めるアプリ、何もしないことで、今と同じように受け止められ続けます。
  - 001（伏せて読む）は止まったままです。

### 確かめ方（安い順。合格の線は先に決めます）
1. **机上で並べる**（pdm、半日、0円）
   - 別の pdm の積読の結果と、4-1 の表を同じ物差しで並べます。
   - 合格の線：「迷う」を示す数字が、スマホか疲れの数字の半分以上あれば、X の本棚の場面を残します。半分未満なら外します。
2. **Takuma の7晩の記録**（1晩1分）
   - 寝る前に3つだけメモします。「読みたいと思ったか」「読んだか」「読めなかったなら、いちばんの理由は迷う、疲れ、スマホのどれか1つ」。
   - 合格の線：「読みたいのに読めなかった夜」が7晩中3晩以上あれば、Takuma 自身がこの悩みに共感していると見ます。そのとき、理由が多く集まった場所で案を選びます。
   - 1人の記録なので、根拠ではなく、共感の確かめとして使います。
3. **身近な5人に過去の行動を聞く**（Takuma、30分。問いは下の Q4）
   - 合格の線：1問目でスマホか疲れの場面を具体的に話す人が、5人中3人以上なら案 A か B に進みます。
   - 3問目で「選ぶのに迷って読まなかった」と話す人が3人以上なら、X の本棚の場面を残します。
4. **10秒の動画で比べる**（designer、1日）
   - A、B、X の象徴の瞬間を、10秒の動画か静止画にします。Takuma と身近な5人に「どれを人に見せたいか」を聞きます。
   - これは映えの確かめで、需要の確かめではありません。
   - 合格の線：6人中4人以上が同じ1つを選ぶこと。
5. **作れるかの確かめ**（tech-lead、1日）
   - X：日本語の縦書きの背表紙20冊の棚を10回撮り、正しく見分けた割合を見ます。
   - A：文庫の見開きを10回撮り、最後の行を正しく切り出せた回数を見ます。
   - 合格の線は、どちらも8割以上を案にします（tech-lead と決めます）。
   - B：盾の画面に、本の一行と縦書きを出せるかを見ます。

## Takuma に決めてほしいこと
1. **物差しの重み**
