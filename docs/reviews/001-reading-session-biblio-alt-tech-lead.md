## 1. 結論と推す案

**答え：できます。** 外部の API を使わなくても、書誌は端末の中だけで作れます。

**推す案は F です。** v1.0 では書誌のための通信を一切しません。
- ISBN はバーコードから取ります。
- 書名、著者、出版社、レーベル、出版年は、奥付（または表紙）を撮って Vision で読み、規則で欄を先に埋めます。違う欄だけ、利用者が写真の行を押して直します（B-tap）。
- どの本でも、手で入れる道（D）は残します。
- 国立国会図書館サーチ（A）は v1.0 に入れません。ADR には「あとで、利用者が選ぶ形で足せる」と戻し方を書いておきます。
- Foundation Models は使いません（理由は spike の結果）。
- 書誌データをアプリに入れる案（C）も v1.0 では使いません。

**いちばん強い反論**
- 登録の手間が、1冊1〜2秒（コードに向けるだけ）から10〜20秒（奥付を開く、撮る、確かめる）に増えます［推測。実機では測っていません］。

**それでも F を推す理由**
1. Takuma が決めたい危険（外部への依存と、法律の不確かさ）が、通信を0件にすればまるごと消えます。「データの収集なし」も、外部送信規律の対象外も、AC-103 も、すべて自明になります。PRD 17 にある「何も外に送らない」と書けない、という縛りもなくなります。

## 3. spike の結果

### 奥付の文字の認識（合成の画像。Mac、macOS 27.0.1、Xcode 27.1）
- **作った画像**
  - よくある奥付の形を、ヒラギノ明朝（W6 と W3）で8枚組みました。横書き5枚（単行本、新書、発行と発売が別、文庫）と、縦書き3枚（新潮文庫で漢数字と改版、創元推理文庫の翻訳、中公文庫の新装版）です。
  - 中身は、書名、著者、発行者、発行所、住所、電話、URL、印刷と製本、注意書き、©、ISBN の行です。
  - それぞれ3つの条件で読みました。きれい、写真に寄せた（−0.5EV、ぼかし1.2、約2.3度、0.6倍）、悪い（−1.0EV、ぼかし1.8、約4.6度、0.45倍）です。
- **読み方**：RecognizeTextRequest（ja-JP、accurate、言語の補正あり）で読み、規則で項目を取りました。
  - 発行所、発行元、発売所などの見出しの後ろを取ります。「株式会社」と「(株)」は除きます。
  - 著者は見出しの後ろを取ります。1字ずつ空いた名前は詰め、2人いれば1人目を取ります。
  - 書名は、メタの行（日付、住所、電話など）を除いたうえで、いちばん大きい行を取ります。同じ大きさで続く行はつなぎます。
  - レーベルは「〜文庫」「〜新書」などで取ります。
  - 出版年は、改版か新装版の行があればその年、なければ最初の日付の年です。和暦と漢数字にも対応しました。
- **結果（8冊ずつ。「3項目」は書名、著者、出版社がすべて正しい冊数）**

### 書誌データの一括提供（案 C）
- **利用条件**
  - 国立国会図書館が作った書誌データは「営利・非営利の目的を問わず、どなたでも無償で利用することができます」とあります。
  - 出典の記載と、加工したことの記載が求められています。
  - 第三者が作った書誌は、その提供元の条件に従います。
- **JAPAN/MARC の毎週の更新**
  - 申し込みは要らず、ZIP で落とせます。週に 2.22〜7.32 MB、件数は 3,112〜6,855件です。
  - 一覧の1年分のうち、私の正規表現で拾えた44本の合計は 167.4 MB、245,137件でした。
  - 入るのは作成が完了した書誌と、更新された書誌です。作成中の新着書誌情報は入りません。
- **全件**
  - JAPAN/MARC (M/S) は約 4.27 GB で、年4回です。問い合わせフォームから申し込みます。
  - OAI-PMH の全件ファイルは、1ファイル5,000件、展開後約30MB で、月1回の更新です。一覧は26,374ファイルあり、1つが gzip で 4,063,134 バイトでした。ほかの提供元の書誌も混ざるので、setSpec で絞る必要があります。
- **大きさを測った**
  - 2026-10-16 提供分を解きました。3,112件のうち、13桁の ISBN があるものが1,676件、そのうち出版年が2026年のものが1,301件です。週1,301件×50週と見ると、新しい ISBN の本は年に約6.5万冊です［推測］。
  - SQLite に、ISBN、書名、著者、出版社、レーベル、年の6列で入れると 103バイト/冊でした。書名の FTS5 trigram を付けると 283バイト/冊で、xz で圧縮するとそれぞれ 37 と 107 バイト/冊です。
  - 国内の ISBN の本の総数は確かめていません［推測。100万〜300万冊なら 103〜850 MB］。
