## 1. 青空文庫の取り扱いの決まり
- 出典：「青空文庫収録ファイルの取り扱い規準」https://www.aozora.gr.jp/guide/kijyunn.html
  - curl で取得し、HTTP 200 でした。
  - 改訂は 2016-01-01、ライセンスの更新は 2022-01-01 です［公開情報］。

### 1-1. 有料のアプリや課金のあるアプリに入れてよいか
- **答え**：入れてよいです。ただし、著作権の切れた作品だけです。
- 原文：
  - 「ファイルは、有償・無償であるかを問わず、自由に複製・再配布・共有することができます。」
  - 「これらのいずれを行うにあたっても、あなたは青空文庫側に対価を支払ったり、了解を求めたりする必要はありません。」
- 使えないもの：
  - 著作権の切れていない作品。原文：「私的使用の範囲を越える利用および複製・再配布は、著作権者の許しがない限り、できません。」
  - 訳した人の権利が残っている翻訳。原文：「書いた人の権利が切れていても、訳した人の権利が生きていれば、その作品は「著作権の切れていない作品」に該当します。」
- 数：作家別作品一覧の CSV では、17,840作品のうち、著作権フラグが「なし」が17,352、「あり」が488です［公開情報 https://www.aozora.gr.jp/index_pages/list_person_all_extended_utf8.zip］。

### 1-2. 表示しなければならないもの
- **答え**：本文の末尾の情報は「残してほしい」という希望です。図書カードと CSV のデータを使うときは、出典の表示が条件になります。
- **本文の情報（希望）**
  - 原文：「ファイルには、作品名・著者名・翻訳者名・底本などに関する情報・入力者名・校正者名・ファイルが作成された日付・修正された日付、「青空文庫作成ファイル：」以下の由来に関する注などが記載されています。」
  - 原文：「利用や複製・再配布・共有にあたって、青空文庫側は、これらの情報が削除されないことを希望します。」
  - 末尾の項目と順番は、https://www.aozora.gr.jp/guide/kisai.html に決まっています。
    - 順番：底本、底本の親本、初出、※の注記、入力、校正、ファイルの作成日、「青空文庫作成ファイル：」の文。
    - このページは「著作権の切れた青空文庫の収録ファイルには、本文に加えて、以下の要素を以下の順序で記載する。」としています。
  - こころの例：底本は「こころ」集英社文庫です。入力は j.utiyama、校正は伊藤時也、1999年7月31日の公開、2010年10月31日の修正です［公開情報 https://www.aozora.gr.jp/cards/000148/files/773_14560.html］。
- **書誌のデータ（条件）**
  - 原文：「データは、有償・無償であるかを問わず、データベースや読書ソフトウェアにおける書誌情報として、活用できます。」
  - 原文：「こうしたデータは、「クリエイティブ・コモンズ 表示 4.0 国際 ライセンス」のもとで提供いたします。」
  - CSV の作品名や初出をアプリに出すなら、CC BY 4.0 の表示が要ります。表示の書き方は要確認です。
- **名前とロゴ**
  - 原文：「「青空文庫」の名称を、再配布に当たっての出所表示として、またパブリック・ドメインの一般名称として、あなたは自由に用いて構いませんが、そのことをもって、青空文庫の関与や認知・許可を示すものではありません。」
  - ロゴは「クリエイティブ・コモンズ 表示-改変禁止 4.0 国際 ライセンス」です［公開情報 https://www.aozora.gr.jp/guide/aozora_bunko_faq.html］。
- **推奨**：義務ではなくても、末尾の情報をそのまま出します。
  - 出す場所は、作品の情報の画面か、最後の回です［推測］。

## 3. 新聞連載の回の思いつき
### 3-1. こころ
- **初出**：「朝日新聞」1914年4月20日〜8月11日［公開情報 青空文庫の本文の末尾］。
- **連載の回数**：110回［公開情報 https://www.city.kawasaki.jp/asao/cmsfiles/contents/0000170/170851/houkokubook2.pdf 。検索の要約］。
- **本文の区切り**：青空文庫の本文は、上・中・下の3部に分かれています。番号の付いた区切りは全部で110あります。
  - 連載の回数と同じなので、区切り1つが新聞の1回分だと見ています［数えたのは公開情報。1回分との対応は推測］。
- **1区切りの長さ**：1,228〜1,765字で、中央は1,468字です（ルビと空白を除く）。
- **読む時間**：
  - 大学生200人が黙読した速さは、平均653字/分（幅300〜1,200字/分）だという紹介があります［公開情報 https://bestcalendar.jp/tools/yomu-jikan 。検索の要約で、元の論文は見ていません］。
  - これで計算すると、1回は平均の人で約2.2分、遅い人（300字/分）で約4.9分です［推測。計算］。「1日5分」に収まります。
- **連載の日数**：4月20日〜8月11日は114日で、その間に110回なので、ほぼ毎日でした［推測。日数から］。「100年前と同じ日付に届ける」形も作れます［推測］。
- **2014年の再連載**：朝日新聞が100年ぶりに再連載しました。
  - 記事の原文：「先ごろ100年ぶりの再連載がスタートしたことがきっかけとなり、文庫の売上も2.5倍を記録。」［公開情報 https://www.lifehacker.jp/article/140620book_to_read/ （2014-06-20）。2.5倍の出どころは書かれていません］
  - 2014年に三四郎も再連載した、という朝日新聞社の発表があります［公開情報 https://san-tatsu.jp/pressrelease/482941/ 。検索の要約］。

## 6. 3人に聞く問いの案と合格の線
- **聞く相手の案**：20〜40代で、すき間の時間に SNS か短い動画を見ていて、この1年に本をほとんど読んでいない人を3人［推測］。
- **問い**：過去の行動を聞きます。
  1. 「最後に、SNS や動画を見ていた時間を別のことに替えようとしたのはいつですか。何をしましたか（アプリを入れた、時間を制限した、本を持ち歩いた、など）。それは何日続きましたか。」
  2. 「最近、毎日少しずつ届くものを読んでいましたか（マンガアプリの1話、メールマガジン、日めくり、名言のウィジェットなど）。最後に開いたのはいつで、何日続きましたか。やめたなら、きっかけは何でしたか。」
  3. 「最後に、教科書に出てくるような名作（漱石、芥川など）を読もうとしたのはいつですか。何で読み、どこまで読みましたか。そのとき、お金を払いましたか（文庫、電子書籍、アプリの課金など）。」
- **合格の線**：聞く前に決めておきます。
  - 問い1：3人のうち2人以上が、この90日の間に、置き換えるために実際にしたことを話す。
  - 問い2：3人のうち2人以上が、毎日届くものを14日以上続けた例を話す。
  - 問い3：3人のうち1人以上が、この1年に名作を読み始め、そのときにお金を払っている。
  - 判定：
    - 問い1と問い2の両方が線に届けば、「名作で進む」の候補にします。
    - どちらかが届かなければ、「やめる」に寄せます。
    - 問い3だけが届かなければ、お金の形を「無料と小さな買い切り」に変えます。
- **後で使う線（前回の報告から引き継ぎ）**：TestFlight で、10人のうち5人以上が、7日のうち4日以上、その日の回を読み終える［推測。G0 で決めます］。
