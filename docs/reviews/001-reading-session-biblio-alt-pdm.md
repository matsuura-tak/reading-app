# 書誌を端末の中だけで扱うときの、製品への影響（pdm の調べもの）

- 書いた役：pdm　日付：2026-10-20。判定ではなく調べものです。
- 根拠の印は［実データ］［公開情報 URL］［推測］の3つです。公開前なので［実データ］はありません。リポジトリの中で確かめた結果（ndl-check、spike）は、PRD の決まりに合わせて［推測。場所］と書きます。
- 公開情報は、すべて 2026-10-20 に開くか検索しました。開かずに検索の要約だけで見たものは、そう書いています。

## 1. 結論と推す案

**推す案は F の1つの形「F1」です。外部の API を使いません。**
- ISBN は、バーコードを端末の中で読んで取ります。
- 出版社は、ISBN の出版者記号を引く表（アプリに入れる）で出します。
- 書名と著者は、手で入れます。または、表紙か奥付を撮り、字を押して入れます。
- A（国立国会図書館サーチ）は v1.0 では作りません。
  - ADR 0004 と契約は「見送り」として残します。
  - 公開後の合図（9 の Q3）しだいで、v1.1 で F2（利用者が選んだときだけ送る A）か C を足せます。

推す理由
1. 芯は書誌に頼りません。
   - 毎晩の入口（ロック画面の一行、しおり、読み始める）は、書名がなくても動きます。
   - 一行があるとき、ウィジェットに書名は出ません。書名のない今の本は「今の本」と出す形が決まっています（design/001-reading-session.md の決定 66、:348）。
   - だから、バーコードを1回読めば、書名を打たずにその夜から読めます。
   - 書誌が効くのは2か所だけです。登録の速さ（O-4。当たり前の品質）と、本の出口の厚み（奥付と、次の1冊の理由。O-3）です。
2. Takuma の怖さを7つに分けると、F1 は7つとも消せます（2 の表）。A は1つも消えません。C は3つ消えますが、新しい本の穴は大きくなります。
3. 作る物が減ります。
   - 通信、順番待ち、問い合わせ直し、NDL の要素から著者を取り出す決まり、出どころの表示が要らなくなります。AC は差し引きで減る見込みです（8 の表）。
   - 課金を入れるかどうかも、国立国会図書館の書誌の網羅と切り離せます（PRD の冒頭 :13、6 の「書誌」の行）。

**いちばん強い反論**
- 書誌が自動で埋まるのは、もう当たり前の品質（Kano の当たり前）です。
  - 見た読書アプリは、どれも書誌を自動で埋めていました。通信しないで登録するアプリは見つかりませんでした（4）。
  - 星3以下の不満の2割前後が登録の失敗です（E-4）。これは「自動で埋まるはず」という期待の裏返しです。
- 手で入れる形にすると、積読10冊を入れる時間が、A の60秒以内（G4-10 の線）から約4〜5分に延びます［推測］。「打つのが面倒」が新しい不満の上位になりえます。
- A が壊れたとき（相手が止まる、本が見つからない）は、手で入れる形に落ちるだけです。つまり A を作れば、F1 の体験はおまけで付いてきます。
- 法律の怖さも小さいかもしれません。送るのは ISBN か書名だけです。規律に当たらないか、除外に入る見込みが高く［推測］、ポリシーに書けば足りる可能性があります。

**それでも推す理由**
- 手間が増えるのは、1冊につき1回です（1冊は1〜3週で読む［推測］）。毎晩の道は0秒のままです。
  - 最初の夜も、バーコード1回で今の本にできるので遅れません。
  - 重くなるのは、最初に積読をまとめて入れるときと、奥付の厚み（レーベルと出版年）だけです。
- 失う情報の重みは小さいです。本を選ぶ理由で、出版社とレーベルは上位12に入りません。上位の「好きな作家の新刊」32.0% と「賞」11.8% は、著者と書名を入れれば F1 でも残ります［公開情報 E-5 https://www.cross-m.co.jp/hubfs/Report/release_files/news_release_20251008.pdf ］。
- 怖さを持ったまま公開すると、名義を持つ個人が次のことを抱え続けます。これは「続けられるか」という事業性のリスクでもあります［推測］。
  - 国立国会図書館への連絡（PRD :1397）
  - 仕様の版の見張り（ADR 0004 の見直す条件）
  - クレジットの文の保守
  - 法律の問い（reviewer の K1）
- 元に戻せます。A の設計と契約は残っていて、送り先を替えるのは1〜2日の見込みです（ADR 0004 の「元に戻す手間」）［推測］。
  - 逆に、A で出してから通信をやめると、ストアの文とプライバシーの説明を後から変えることになります［推測］。

**考えを変える条件**
- 怖さが法律の問いだけで、外のサービスに頼ること自体は怖くないなら、A のままのほうが製品としてよいです。送る情報と送り先をポリシーに書く形（ADR 0004 の表の 18）か、F2（同意を取る形）です。
- V-a（7）で、Takuma が自分の積読10冊を F1 の形で入れて、1冊あたり平均30秒を超えたら、F2 を推します。
- V-b で、出版者記号の表で出版社が決まる本が9割に届かなければ、奥付の出版社の行も「入れたときだけ」にします（F1 のまま）。

**作らない場合（A のままにする）に起きること**
- K1（外部送信規律）に、ポリシーに書くか、専門家に聞くかで答える必要が残ります。
- 公開の前に、Takuma の名前で国立国会図書館へ連絡を出します。
- 自動で埋まる登録、5行の奥付、「同じレーベル」の理由は残ります。

各行の根拠
1. 法律
   - 総務省のページで読めた範囲です［公開情報 https://www.soumu.go.jp/main_sosiki/joho_tsusin/d_syohi/gaibusoushin_kiritsu.html 。文字化けがあり、読めた所だけ］。
     - 対象は電気通信事業者（Web サイトの運営者とアプリの提供者）です。
     - 挙がっているサービスは、メッセージの媒介、SNS、検索、ホームページの運営（オンラインの媒体）です。
     - 取る措置は、通知・公表、同意を取る、オプトアウトのどれかです。
     - サービスの提供に必要な情報（OS の情報など）は対象外です。
     - 施行は 2023-06-16 です。
   - 次の2つは法律の判断なので、pdm には決められません。見込みは「当たらないか、除外に入る」です［推測］。
     - サーバーのない読書アプリが、この役務を出す者に当たるか。
     - ISBN の問い合わせが、除外の「必要な情報」に入るか。
2. 相手が止まる、変わる
   - 無料の書誌サービスが小さくなった前例として、openBD の縮小があります［公開情報 https://openbd.jp/news/20230725.html （E-11）］。
   - NDL サーチの仕様書は第1.5版（2026-09-25）で、版が上がったら見直す決まりです（ADR 0004）。
3. 条件が変わる
   - 全件のデータについて、「JAPAN/MARCの全件データも提供しています（申し込みが必要です）」とあります。週ごとの更新分も取れます［公開情報 https://www.ndl.go.jp/data/data_service/jnb ］。
4. 新しい本の穴
   - A の数は ADR 0004 と ndl-check から取りました［推測。docs/adr/features/001-reading-session-ndl-check.md］。15〜28日前に出た本は10件中9件見つかりました。
   - C について、全国書誌は「出版物が国立国会図書館に届いてから約1か月後に提供」、新着書誌情報は約4日後です［公開情報 上の jnb のページ］。
5. 利用者の信頼
   - 6つのアプリの最近のレビュー910件を見ました（4）。書誌を外へ送ることへの不安を書いたものは0件でした。
6. 審査とプライバシーの表示
   - A でも「データの収集なし」と申告する決定です（ADR 0004 の表の 16）。審査で問われる余地は、ADR 0004 の反論2に書かれています。
7. 名義を持つ本人の手続きと保守
   - PRD :1397（Takuma の名前で連絡）、AC-93（クレジット）、ADR 0004 の見直す条件です。

補足
- 奥付は、PRD 9 :160 の「データのない行は出さない」で、行が減っても画面は崩れません。
- 次の1冊の理由で、受賞と、新しい本を積読に加える動き（AC-83）は、端末の中の一覧から来るので、どの案でも残ります（PRD 12 :1246）。
- F2 は、既定では F1 と同じです。オンにした人だけ A と同じになります。
- 4つの力で見ると、次のようになります。
  - 押し：A に残る怖さ。
  - 引き：「通信しない」安心と、機内モードでも全部動くこと［推測］。
  - 不安：打つ手間と、書名のない本棚。
  - 習慣：ほかのアプリで自動で埋まることに慣れていること。
  - 不安と習慣を下げる手当て：書名はあとでよいこと、撮って押す入力、表で埋まる出版社、最初の登録の画面で「このアプリは通信しません」と1行で言うこと（形は designer）。

## 5. 「何も外に送らない」の価値と、Takuma の基準

掲載文とプライバシーの表示
- 表示そのものは変わりません。A でも「データの収集なし」で出す予定だからです（ADR 0004）。Spine も、問い合わせをしながら "Data Not Collected" です［公開情報］。
- 変わるのは次の2つです。
  - 確かさ：審査で読み方を問われなくなります。
  - ストアの文：「このアプリは通信しません」と書けるようになります。今の PRD 17 :1361 は「何も外に送らない」と書くことを禁じています。
- いちばん近い ToRead は「データの収集なし」ではありません［公開情報］。この違いは、A でも F1 でも出せます。
- 確かめやすさ：App プライバシーレポートで、このアプリの通信先が0件と出れば、審査の担当もレビューを書く人もすぐに確かめられます（G4-20 の形）［推測。StoreKit の購入の通信がレポートにどう出るかは、tech-lead に確かめてほしい］。
