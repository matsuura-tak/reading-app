# 報告：読書アプリの方向の調べもの その1（角度①と②）

- 書いた役：pdm
- 調べた日：2026-10-16。評価の数とレビューは、その日の App Store の値です。
- リポジトリのファイルは書いていません。一時ファイルはスクラッチパッドにだけ置きました。

## 0. 結論
- **①（スマホを開いた瞬間を読書に変える）**
  - 需要はいちばん強いです。スマホ依存を自覚している人は45%です。日本で使われているスマホ制限アプリには、評価が数千〜2.7万件のものが並びます。
  - ただ、日本にはすでに強い制限アプリがあります。そのうち one sec と Opal は、日本語の画面がある海外のアプリです。
  - 「読書に誘う」部分は海外でもまだ育っていません。US の Pagelock は評価7件、ReadUp は9件です。
  - Takuma の仮説「日本になく、海外で発展している」には、どちらの半分も当てはまりません。
- **②（読んだことを忘れない）**
  - 需要の証拠は①より弱いです。働く人の読書の課題で2位にとどまります。
  - 一方、海外の先行の Readwise は、日本では仕組みの上で弱いです。amazon.co.jp の Kindle とは同期できないと公式に書いています。画面は英語だけで、日本での平均は2.89です。
  - 日本の専用アプリは2022年から更新が止まっています。
  - 最初の発想「読む時間そのものが美しくなる」にも近いです。
- **pdm としては②を推します。** ただし、作る前に「紙の本の一節を撮る手間を、人が越えるか」を確かめることが条件です。
- **いちばん強い反論：** 読書の課題の1位は「時間の確保」（39.5%）で、「忘れる」は2位です。読む人が減っている中で、すでに読む人の悩みだけを解くと、市場が狭くなります。さらに、一節を撮るにはスマホを手に取る必要があり、「スマホから離れたい」という気持ちと逆を向きます。

## ① スマホを開いた瞬間を、読書に変える

### ①-1 日本の需要
- **読書が減った理由の1位はスマホ**
  - 16歳以上の62.6%が1か月に1冊も読みません。69.1%が読書量が「減っている」と答えました。

### ①-4 日本の空き
- **海外の先行が日本で弱い理由**
  - 日本語の画面がない：ScreenZen、Unrot、Pagelock。［公開情報 lookup の言語の欄］
  - 翻訳が足りない：one sec。［公開情報 RSS］
  - 値段が高い：Opal。［公開情報 RSS］
  - 日本の評価の数は US の1〜2%にとどまる：ScreenZen は 602 対 51,682、Unrot は 98 対 56,937。［公開情報］
- **日本の競合で埋まっていないか**
  - ブロックすることと、開く前に立ち止まらせることは埋まっています。
  - 読みかけの本に誘うことは空いています。［公開情報 ①-3］
- **ただし、空きが空いている理由に注意がいります。** 読書に誘う型は、US でも育っていません（Pagelock 7件、ReadUp 9件）。空いているのは、需要が弱いからかもしれません。［推測］

### ①-5 独自性の種
1. **伏せた時間で開く。**
   - SNS を開こうとすると、止める画面に「『〇〇』の続き、伏せて10分」と出ます。001 の「伏せて読む」で読んだ時間が、そのまま記録として残ります。
   - Pagelock は本のページを撮ってクイズに答える仕組みです。ReadUp はアプリの中で本を読みます［公開情報 説明文］。伏せた時間そのものを「スマホを触らなかった証し」にする作りは、見た範囲にはありませんでした［公開情報。見たのは上位だけ］。
   - 価値は［推測］です。
2. **ブロックしないで、思い出させる。**
   - ロック画面とホーム画面のいちばん目につく所に、読みかけの一節と続きのページを置きます。止める仕組み（Screen Time の API）に頼らないので、抜け道や不具合との戦い（①-3 の a と b）を避けられます。［推測］

### ①-7 いちばん強い反論と、いちばん安い確かめ方
- **反論**
  - SNS を開こうとする瞬間（通勤中、ベッド、トイレ）、紙の本は手元にないことが多いはずです。誘っても「今は無理」で外れ続けて、ただのブロッカーになります［推測］。
  - US でも、伸びているのは単純なブロッカーと、何をしても稼げる交換型です。読書に絞った型は伸びていません［公開情報 ①-2］。
- **確かめ方（安い順）**
  1. **Takuma が7日間試す。** iOS のショートカットにある「App を開いたとき」の自動化で、SNS を開くと「『読みかけの本』p.xx の続きを10分」と出るようにします。これでアプリを作らずに試せます（この自動化が今も使えるかは［推測］で、要確認）。
     - 数えるもの：止まった回数、本が手の届く所にあった回数、実際に本を開いた回数。
     - 合格の線：本が手の届く所にあった割合が50%以上、かつ本を開いた割合が20%以上［推測。線は Takuma と決める］。
  2. **5人に、過去の行動を聞く。**
     - 「最後に SNS を思ったより長く見てしまったのはいつ？　そのとき、読みかけの本はどこにあった？」
     - 「スマホの時間を減らすために入れたアプリや設定は？　今も使っている？　やめたなら、なぜ？」
