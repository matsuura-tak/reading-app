## 結論
- 3体とも、v1.0 では外部の API を使わない形を推した。
- 推す形（F。3体の推す形の重なり）
  - 書誌のための通信は0件。国立国会図書館サーチ（A）は v1.0 に入れない。あとで「利用者が選んだときだけ使う」形で足せるよう、戻し方を ADR に書いておく。
  - 登録の流れ
    1. バーコードで ISBN を読む。
    2. 奥付か表紙を写す。
    3. アプリが規則で欄（書名、著者、出版社、レーベル、出版年）を先に埋める。
    4. 違う欄は、利用者が写真の行を押して直す。
    5. 確かめて加える。
  - 手で入れる道は、いつも同じ画面に置く。
  - 外すもの
    - 書名で探す道（AC-4〜AC-6）：外部の API なしでは元のデータがない。
    - 端末の AI（Foundation Models）：規則より正しくならず、使える機種も約4〜5割。
    - 書誌データをアプリに入れる形（C）：数十〜数百 MB になり、新刊が遅れ、毎月の更新が要る。v1.0 では使わない。
- これで消えるもの（pdm の怖さの7種類は、すべて消える）
  - 法律（外部送信規律）の問いと、相手が止まる・変わる危険
  - 国立国会図書館への連絡（PRD :1397）、出どころの表示（AC-93）、申請の問い（18 の Q5）
  - 新刊の穴（出て14日以内の本は5件中2件が0件だった）
  - ラテン文字の著者の形（G1-13。奥付には表紙と同じ「アンソニー・ホロヴィッツ」が載る）
  - 課金を入れる条件から、書誌の網羅が外れる
- 「このアプリは通信しません」と、ストアの文に書けるようになる（今の PRD 17 は、書くことを禁じている）。

## いちばん強い反論
- 登録が重くなる。
  - 1冊の登録は、バーコードだけの数秒から、10〜20秒になる［推測］。
  - 積読10冊をまとめて入れると、約1分が約2.5〜4分になる［推測］。
- 書誌が自動で埋まるのは、もう当たり前の品質。見た読書アプリはどれも外部で埋めていて、通信なしで登録するアプリは見つからなかった（pdm の 4）。
- 精度がまだ確かでない。合成の奥付で、書名・著者・出版社の3項目がそろったのは、写真に寄せた条件で8冊中5冊（tech-lead の spike）。本物の写真ではさらに下がる見込み。
- A の法律の不安は、「公表」（送る情報と送り先をポリシーに書く）で足りるかもしれない［推測。法律の判断］。

それでも推す理由
- 重くなるのは1冊につき1回で、毎晩の道（ロック画面の一行、伏せて読む）は0秒のまま。
- 手元の本の字を写すので、「見つからない」と「違う本を当てる」が仕組みの上で起きない。
- 出す前なら、設計の書き直しだけで済む。逆に、A で出してから通信をやめるのは、ストアの文とポリシーの書き直しが要る。

## 3体で分かれた所と、指揮役の裁定
1. **バーコードを残すか**
   - tech-lead と pdm は残す、designer は外す（奥付から写せば ISBN は要らない、という考え）。
   - 裁定：残す。ISBN で本の重なりを確かめられ、写す前に「この本」を決められる。奥付に ISBN の行がない本もある。
2. **書名なしで加えてよいか（書名はあとで入れる）**
   - pdm は認める（バーコード1回で、その夜から読める）、designer は避ける（書名のない本の状態がまとめて消える）。
   - 裁定：PRD を直すとき pdm が決める。指揮役の推奨は、写す画面に「あとで」を置き、飛ばしたときだけ書名なしの本（決定 66 の「今の本」）にする形。
3. **出版社を ISBN の出版者記号の表から出すか**
   - pdm は推す、tech-lead は v1.0 では推さない（国立国会図書館のデータから作ると、出典の表示が要る）。
   - 裁定：使わない。出版社は、奥付の「発行所」の行から取る。出典の表示をまったく要らない形にするため。

## 確かめ（Takuma に頼む。約30分）
- 中身：本物の奥付10冊を撮る（tech-lead の報告の 7）。
  - 選ぶ本：文庫4冊（うち2冊以上は縦書きの奥付）、新書2冊、単行本3冊、翻訳書1冊。うち1冊は2週以内に買った本。
  - 撮り方：ふだん読む明かりの下で、自然に開いたまま撮る。5冊は、手に取ってから撮り終えるまでの秒数を測る。
  - 渡し方：写真を Mac に送る。写真はリポジトリに入れず、終わったら消す。
- 合格の線（写真を見る前に決める［推測の線］）
  - 書名と著者が、打ち直さずに行を押すだけで正しく入る本が10冊中8冊以上。
  - 出版社が10冊中8冊以上。
  - 撮り終えるまでの秒数の中央値が10秒以内。
- 届かなければ：F に A を「利用者が選ぶ形」で足すか、手で入れる形だけにするかを、もう一度 Takuma に聞く。
